# Bella Vista Restaurant

Authentic Italian cuisine website for Bella Vista, a restaurant serving fresh pasta, wood-fired pizzas, and traditional Italian dishes in the heart of the city.

## About

This is the website for Bella Vista. It introduces the restaurant, showcases the menu, and helps visitors learn about the dining experience and get in touch.

## Features

- Responsive design that works on mobile, tablet, and desktop
- Menu showcasing fresh pasta, wood-fired pizzas, and traditional Italian dishes
- About section with the story of the restaurant
- Contact details and location
- SEO-friendly page title and meta description

## Tech Stack

- HTML5
- CSS3
- Hosted on Vercel

## Getting Started

1. Download or clone this project.
2. Open `index.html` in your browser.

No build step or installation is needed.

## Deployment

This site is deployed on [Vercel](https://vercel.com).

Live site: https://your-project-name.vercel.app

To deploy your own copy:

1. Push the project to a GitHub repository.
2. Log in to Vercel and click **Add New Project**.
3. Import the repository.
4. Leave the build settings empty (it is a static site) and click **Deploy**.

Every time you push changes to the repository, Vercel redeploys the site automatically.

## Customization

- Update the restaurant name, description, and menu items in `index.html`.
- Replace the images in the `images/` folder with your own photos.
- Edit colors and fonts in `css/style.css`.
